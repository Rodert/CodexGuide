# 第一个任务

## 适合谁

已登录 Codex，准备让它在练习目录中完成一次低风险任务的读者。

## 开始前

准备好上一章创建的空文件夹。任务中只会创建一个简单网页，不会要求连接账号、安装不明插件或读取工作资料。

## 操作步骤

1. 在 Codex 中创建项目，并选择 `codex-first-project` 作为工作目录。
2. 复制下面代码框中的文字，粘贴到任务输入区并发送。不要把包围文字的三个反引号一起复制：

<!-- MEDIA: screenshot | file: images/getting-started/07-select-workspace.png | capture: Codex App 已选择 codex-first-project 作为工作目录的界面 -->

```text
请在当前空目录创建一个个人介绍网页。

内容：姓名“小王”，兴趣为阅读、旅行、摄影；
联系按钮链接到 mailto:hello@example.com。

要求：
1. 只使用 HTML 和 CSS，文件为 index.html 和 style.css。
2. 页面简洁，手机上也能正常阅读。
3. 不安装依赖，不使用外部图片或服务。
4. 完成后说明创建的文件，以及如何打开网页。
```

3. 等任务结束，观察它列出的文件名和保存位置。生成过程中的进度说明，不等于最终已经保存。
4. 如果请求写入权限，确认路径仍是练习目录后再决定是否允许；当前策略已经允许的操作也可能不弹窗。

<!-- MEDIA: screenshot | file: images/getting-started/07-first-task-result.png | capture: Codex 完成网页任务后的结果摘要和创建文件列表 -->

`mailto:` 表示交给设备的邮件应用处理，并不是收集留言的后端接口。这里先学习创建网页，不涉及发送邮件服务。

## 完成检查

打开练习文件夹，应该能看到 `index.html` 和 `style.css`。如果只有聊天中的代码、目录没有文件，继续说：“请将代码实际保存到当前练习目录。”

这节先确认文件存在；下一节再检查网页内容和显示效果。

如果文件管理器隐藏扩展名，可以打开“显示文件扩展名”，确认文件不是 `index.html.txt`。看到额外的依赖目录或安装请求时，先问它为什么需要，重申本练习只使用两个静态文件。

## 常见问题

**生成出来的页面和示例不一样怎么办？** AI 每次生成的布局可能不同，只要内容、文件和约束满足要求，就可以继续。想对照一个能打开的结果，可以查看 [参考网页](/examples/personal-page/index.html)；它是示例，不要求像素级一致。

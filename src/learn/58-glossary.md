# 术语表

遇到陌生词时回来查，不需要先背完。优先记住工作目录、Diff 和验证，它们直接关系到你是否知道改了什么。

## 任务与环境

| 术语 | 通俗解释 |
| --- | --- |
| Agent | 能围绕目标分步骤调用工具、处理任务的系统 |
| Prompt | 你给 AI 的任务描述和要求 |
| 上下文 | 当前任务能参考的信息，如消息、文件和命令输出 |
| 工作目录 | 本次任务主要读取、修改文件的位置 |
| CLI | 在终端中使用的命令行工具 |
| IDE | 编辑、运行和调试代码的开发环境 |
| 依赖 | 项目运行或构建需要的其他软件包 |
| 构建 | 将源文件转换为可交付产物的过程 |

## 改动与验证

| 术语 | 通俗解释 |
| --- | --- |
| Diff | 文件新旧内容的差异 |
| Commit | Git 中保存的一次版本记录 |
| Branch | 组织一条开发路线的分支 |
| Push | 将本地提交上传到远程仓库 |
| PR | 提交一组改动供审查、讨论和合并的请求 |
| Review | 检查改动是否合理、是否引入问题 |
| 回归 | 修改后原本正常的功能出现问题 |
| CI | 由仓库事件等触发的自动化检查流程 |
| Worktree | 同一 Git 仓库的另一个工作目录 |

## 规则与扩展

| 术语 | 通俗解释 |
| --- | --- |
| AGENTS.md | 给 Agent 阅读的项目约定文件 |
| Skill | 可重复使用的任务流程和配套资源 |
| Plugin | 打包安装和分发相关能力的工具包 |
| MCP | 连接模型工具与外部能力的一种协议 |
| Hook | 在受支持事件发生时运行程序的机制 |
| 沙盒 | 限制文件、命令或网络等操作范围的环境机制 |
| 审批 | 对特定操作进行允许、拒绝或确认的过程 |
| API Key | 调用服务时使用的凭证，应像密码一样保护 |

**容易混淆：** Commit 不等于 Push，Push 不等于部署；Skill 不等于模型；配置了工具不等于完成外部授权；任务结束也不等于验证通过。

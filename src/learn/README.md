## 怎样跟着操作

先按入门篇做到“生成网页、打开结果、继续改一次”，再选自己需要的工具与实战章节。操作时只复制代码框里的内容，命令在终端执行，任务描述发到 Codex 输入区；不要把代码框标记一起复制。

需要统一起点时，可以下载 [个人网页练习包](/examples/personal-page.zip) 或 [JavaScript 练习包](/examples/js-practice.zip)。先解压到独立目录，再选择实际包含项目文件的那一层。前者浏览器即可打开，后者需要 Node.js 22 或更高版本。

每节先看前置条件，再逐步操作，最后对照预期结果。明确标注待核对的配置、接入和更新记录可以先跳过；不要为了连贯阅读而猜测填写。

# Plugins

Plugin（插件）是一种打包和分发能力的方式。可以把 Skill 想成一道菜的做法，插件则像一个工具包：里面可能有多个 Skill、工具配置和配套资源。

## 插件、Skill 和 MCP 的关系

| 名称 | 主要解决的问题 |
| --- | --- |
| Skill | 做这类任务时采用什么方法 |
| MCP | 通过什么协议连接外部工具或数据 |
| Plugin | 怎样把相关能力安装、管理和分发 |

一个插件不一定包含所有这些内容，安装了插件也不一定已经完成外部服务登录。

## 使用前看什么

先看来源和说明，再看它会访问什么：本地文件、浏览器、外部账号，还是远程工具。然后确认当前入口支持该插件、已启用，并完成必要的授权。

例如，安装一个文档处理插件后，先在不含隐私的示例文件上执行小任务。检查是否能读取文件、生成结果，并说明实际使用了什么能力。

## “安装成功”但不能用怎么办

按顺序检查：插件是否启用；当前任务是否已加载相关能力；依赖软件是否可用；外部账号是否授权；组织策略是否允许。按产品提示重新加载或新建任务，再测试一个最小操作。

不要通过重复安装或放开全部权限猜原因。具体安装界面和命令需按当前版本核对，本节先说明使用和排查顺序。

**完成检查：** 你能说清这个插件增加了什么，以及它是否还需要外部服务或凭证。

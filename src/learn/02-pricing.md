# 订阅与计费

## 适合谁

准备开始使用 Codex，但还不清楚应该登录 ChatGPT、使用 API，还是考虑第三方方案的读者。

## 开始前

套餐、价格、可用地区、额度和功能开放范围都会变化。本章不写死具体金额；你准备付费或升级前，始终以 OpenAI 的账户页面和官方说明为准。

## 先分清三件事

### 1. ChatGPT 账户

大多数个人用户会通过 ChatGPT 账户登录 Codex。你看到的可用功能与额度，取决于当前账户、所在工作区和官方开放范围。对第一次体验的人，这通常是最直接的起点。

### 2. OpenAI API 账户

API 账户适合把模型能力接入程序、自动化脚本或 CI 流程的场景。它的计费、密钥管理和可用能力与 ChatGPT 订阅并不是一回事。不要把 API key 发到聊天记录、截图、代码仓库或公开文档中。

### 3. 第三方模型或中转服务

有些服务会提供兼容接口、第三方模型或代充方案。这类服务的价格、稳定性、隐私条款和功能边界由服务商决定，不等于 OpenAI 官方 Codex 能力。后面的第三方模型专题会单独说明 DeepSeek 等方案的适用场景与风险。

## 新手怎么选

如果你的目标是先完成教程里的第一个任务，优先使用你自己可正常登录的官方账户，不要一开始就配置 API、第三方地址或复杂的环境变量。

下面这些情况可以进一步研究 API，但自动化并不一定要求 API Key，也要看所用工具支持的认证方式：

- 你需要把 Codex 接进脚本、自动化或持续集成。
- 你需要按程序调用、按用量管理成本。
- 你已经知道如何妥善保存环境变量和密钥。

## 使用前检查清单

1. 在准备使用的 Codex 入口登录，打开账户、套餐或用量说明。不同版本的名称可能不同，先找头像或设置中的账户信息。
2. 核对账号和工作区，阅读当前权限、额度与限制提示，不要拿另一个账户的付款记录作判断。
3. 若能开始任务，先发送“只回复一句你好，不读写文件”。成功只能说明当前可以对话，不能证明后续所有工具和额度都可用。
4. 如果被限制，记下原文，区分“额度不足”“无访问权限”和“登录/网络失败”。只有明确属于套餐或额度问题时，再考虑付费方案。

**完成结果：** 你知道自己这次用哪种方式登录、在哪里查看用量，以及是否可以继续后面的练习；不要求先购买 API 额度。

## 常见问题

**有 ChatGPT 订阅，还需要 API key 吗？** 不一定。是否需要 API key 取决于你使用的入口和任务类型。第一次跟练教程不要求配置 API key。

**有 API 余额，为什么 App 仍然受限？** 先确认 App 当前使用的认证方式。API 账单和产品账号权限不是同一回事，不要直接重复充值。

**界面里找不到用量入口怎么办？** 从当前账户页和官方说明继续查。无法确认时，先记录提示，参考 [安装与登录问题](./48-install-login.md)，不要仅凭一次失败就付费升级。

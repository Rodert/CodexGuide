# 订阅与计费

## 适合谁

准备开始使用 Codex，但还不清楚应该登录 ChatGPT、使用 API，还是考虑第三方方案的读者。

## 开始前

套餐、价格、可用地区、额度和功能开放范围都会变化。本章不写死具体金额；你准备付费或升级前，始终以 OpenAI 的账户页面和官方说明为准。

## 先分清三件事

### 1. ChatGPT 账户

大多数个人用户会通过 ChatGPT 账户登录 Codex。你看到的可用功能与额度，取决于当前账户、所在工作区和官方开放范围。对第一次体验的人，这通常是最直接的起点。

### 2. OpenAI API 账户

API 账户适合把模型能力接入程序、自动化脚本或 CI 流程的场景。它的计费、密钥管理和可用能力与 ChatGPT 订阅并不是一回事。不要把 API key 发到聊天记录、截图、代码仓库或公开文档中。

### 3. 第三方模型或中转服务

有些服务会提供兼容接口、第三方模型或代充方案。这类服务的价格、稳定性、隐私条款和功能边界由服务商决定，不等于 OpenAI 官方 Codex 能力。后面的第三方模型专题会单独说明 DeepSeek 等方案的适用场景与风险。

## 新手怎么选

如果你的目标是先完成教程里的第一个任务，优先使用你自己可正常登录的官方账户，不要一开始就配置 API、第三方地址或复杂的环境变量。

只有在下面的情况，才建议尽早研究 API：

- 你需要把 Codex 接进脚本、自动化或持续集成。
- 你需要按程序调用、按用量管理成本。
- 你已经知道如何妥善保存环境变量和密钥。

## 使用前检查清单

1. 确认可以正常登录自己的账户。
2. 在账户页面确认当前可使用的功能和额度提示。
3. 不确定时，先完成低风险练习任务，不要直接开始长时间或批量任务。
4. 使用 API 时，只通过环境变量或受信任的密钥管理方式保存 key。

## 常见问题

**有 ChatGPT 订阅，还需要 API key 吗？** 不一定。是否需要 API key 取决于你使用的入口和任务类型。第一次跟练教程不要求配置 API key。

**能否把价格写进教程？** 可以，但价格表必须标注“最后核对日期”和官方链接。价格变化时，先更新截图和文字，再发布。

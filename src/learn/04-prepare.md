# 准备工作

## 适合谁

第一次使用 Codex，想在不影响真实文件的前提下完成一次练习任务的读者。

## 开始前

准备一台电脑、可用的 Codex 登录方式，以及一个新建的空文件夹。这个文件夹只用于教程练习，不要放入工作项目、密码或重要资料。

再准备一个浏览器，用来查看生成的网页。本次练习只使用 HTML 和 CSS，不要求先安装数据库、学习框架或购买服务器。

## 操作步骤

1. Windows 打开文件资源管理器，macOS 打开访达，进入自己的“文档”目录。
2. 在空白处通过右键菜单新建文件夹，命名为 `codex-first-project`。
3. 双击打开，确认里面没有其他文件。后面选择工作目录时，要选择这一层，而不是它外面的“文档”。
4. 暂时保持这个窗口打开，安装并登录后返回 Codex 选择同一个目录。

工作目录就是 Codex 本次处理文件的主要位置。不要为了方便直接选择整个桌面或下载目录，选中刚建的练习文件夹即可。

## 准备练习内容

后面统一使用虚构信息：姓名“小林”，兴趣“阅读、旅行、摄影”，联系邮箱 `hello@example.com`。这样不需要在公开示例里使用自己的隐私信息。

完成时，你应该能找到这个空目录，并知道后续生成的网页会保存在哪里。

如果只想从后面的实战开始，可以下载 [个人网页练习包](/examples/personal-page.zip)，先解压，再打开其中的文件夹。第一次跟练仍建议保持空目录，让 Codex 自己创建文件；不要把示例包直接覆盖到已有作品上。

## 常见问题

**可以直接在工作项目里练习吗？** 不建议。第一次使用时，单独的练习目录更容易观察修改，也能避免误改真实项目。

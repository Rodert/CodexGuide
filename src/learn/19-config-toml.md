# config.toml

::: info 本章待核对
配置字段、存放位置和优先级需要对应当前版本核实，本章暂不提供可直接覆盖使用的配置。
:::

如果你只是想让 Codex 遵守项目风格、使用指定测试命令，先完成 [AGENTS.md](./18-agents-md.md)，不必为此修改工具配置。

确实需要调整设置时，先通过 [官方配置参考](https://developers.openai.com/codex/config-reference/) 确认适用入口和版本，备份原文件，一次只改一项；不要直接用网上整份配置覆盖自己的设置。

可先继续阅读 [上下文与记忆](./20-context-memory.md)。

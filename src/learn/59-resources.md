# 推荐工具与资源

页脚的资源入口适合放在这里：它们服务于已经读完文章、准备开始下一步的人，不会打断教程主线。链接会随着工具和教程更新而调整；涉及账号、套餐和功能范围时，以目标网站的说明为准。

## 创作工具

| 资源 | 适合做什么 | 入口 |
| --- | --- | --- |
| AI 画图 | 生成插图、产品图和页面配图 | [打开图像生成指南](https://platform.openai.com/docs/guides/image-generation) |
| AI 视频 | 生成短视频和视频素材 | [打开 Sora](https://openai.com/sora/) |

## 编程与学习

| 资源 | 适合做什么 | 入口 |
| --- | --- | --- |
| AI 编程 | 在项目中完成开发、排错和代码审查 | [打开 Codex](https://chatgpt.com/codex) |
| Codex 视频教程 | 观看官方产品视频和演示 | [打开 OpenAI 视频页](https://www.youtube.com/@OpenAI/videos) |
| Codex 图文教程 | 了解桌面 App 的项目、对话和权限界面 | [查看桌面 App 教程](./06-app-overview.md) |
| Skills | 为 Codex 安装或编写可复用的工作能力 | [查看 Skills 教程](./23-skills.md) |

## 放置建议

底部可以直接放，但控制在 5 到 7 个高频入口最合适。建议按使用场景分组，并让外部链接在新标签页打开；链接较多、需要解释或会经常替换时，统一落到本页管理。

当前页脚中的链接就是一套可用案例。要替换成自己的管理地址，只需修改 `src/.vuepress/theme.ts` 里的 `site-footer__links` 区域即可。

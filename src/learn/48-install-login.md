# 安装与登录问题

先分清失败发生在哪里：安装程序打不开、浏览器授权失败、返回 App 后仍未登录，还是登录后没有使用权限。这些问题不要用同一种办法处理。

## 按现象检查

| 现象 | 先检查什么 |
| --- | --- |
| 安装包无法运行 | 官方来源、系统版本、处理器类型和设备管理限制 |
| 授权页面打不开 | 网络、代理及浏览器显示的完整错误 |
| 浏览器提示成功，App 未登录 | 是否返回正确应用、是否有多个实例或账户 |
| 登录了但功能不可用 | 当前账户、工作区和具体权限提示 |

先尝试一次正常关闭并重新打开应用，记录是否稳定复现。不要反复删除配置、重装和切换账户，否则容易丢失判断线索。

## 给排查提供什么信息

```text
我使用的是 [App / CLI / 编辑器扩展]。
系统和工具版本：[实际版本]
失败步骤：[从哪里开始，在哪一步失败]
完整提示：[脱敏后的文字]
已尝试：[操作及结果]
请先判断问题属于安装、授权回调还是账户权限，不修改配置。
```

截图隐藏邮箱、验证码、令牌和回调地址中的敏感参数。不要把登录链接或授权码发送给第三方“代登录”。

## 什么时候需要其他人处理

公司设备被策略阻止，找管理员；账户权益或支付不符，联系对应服务的支持渠道。安装成功不能解决账户权限，API Key 也不能代替所有产品授权。

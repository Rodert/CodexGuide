# 检查任务结果

## 适合谁

已经让 Codex 完成任务，想确认它是否真的完成正确的修改的读者。

## 开始前

保留当前对话和练习文件夹，不要急着删除生成的文件。

## 操作步骤

1. 查看 Codex 的最终说明，确认它列出了创建或修改的文件。
2. 在文件夹中打开 `index.html` 或 Codex 提供的预览入口。
3. 对照你的需求检查姓名、兴趣、按钮和页面样式是否存在。
4. 给 Codex 一条明确的后续需求，验证它能在已有文件基础上继续修改。

## 常见问题

**只要 Codex 说完成就可以吗？** 不可以。始终打开产物、检查关键内容，并在有代码任务时运行对应测试或预览。

# 官方资料索引

教程适合按步骤学习，官方资料适合核对最新的入口、配置和功能边界。遇到版本差异时，先查与你正在使用的入口对应的页面。

## 从问题找到资料

| 想确认什么 | 官方入口 |
| --- | --- |
| 产品概况与起步 | [Codex 文档](https://developers.openai.com/codex/)与[快速开始](https://developers.openai.com/codex/quickstart/) |
| 桌面应用 | [Codex App](https://developers.openai.com/codex/app/) |
| 命令行使用 | [Codex CLI](https://developers.openai.com/codex/cli/) |
| 编辑器扩展 | [Codex IDE](https://developers.openai.com/codex/ide/) |
| 计费与模型 | [定价说明](https://developers.openai.com/codex/pricing/)与[模型说明](https://developers.openai.com/codex/models/) |
| 项目规则 | [AGENTS.md 指引](https://developers.openai.com/codex/guides/agents-md/) |
| 扩展能力 | [Skills](https://developers.openai.com/codex/skills/)与[MCP](https://developers.openai.com/codex/mcp/) |
| 设置项 | [配置参考](https://developers.openai.com/codex/config-reference/) |
| 发布变化 | [Codex Changelog](https://developers.openai.com/codex/changelog/) |

链接页面可能调整；若某个地址不可用，从文档首页按主题查找。账户实际可用性仍要结合自己的登录页面和组织设置。

## 读官方说明时注意什么

跟练时只核对一个问题：例如 CLI 无法启动，就打开 CLI 页，先确认支持的安装渠道，再对照本机 `codex --version` 和 `codex --help`。不要同时翻阅云端和 API 文档后，把不同入口的要求混到一起。

先确认页面讲的是 App、CLI、IDE 还是云端；再看版本、前置条件、限制和示例。命令可复制，不代表适合直接粘贴到生产环境。

涉及价格、型号和配置时，记录查阅日期以及实际使用版本。不能打开来源时，不把搜索摘要或旧截图当成已经核实的完整说明。

页面打不开时记下地址和错误，先跳过依赖该事实的操作。只有成功阅读了支持结论的正文，才能把它记为已核对；一个能点击的链接本身并不能证明内容正确。

## 怎样给教程提问题

附上文章地址、工具版本、官方页面和具体差异，隐藏账户与凭证。清楚的复现信息，比“教程过时了”更容易帮助作者更新。

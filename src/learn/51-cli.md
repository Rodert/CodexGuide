# CLI 问题

CLI 出错时，从“命令能否找到”开始，再检查登录、项目环境和具体任务，不要一上来就重装全部开发工具。

## 命令找不到

在终端执行：

```bash
codex --version
codex --help
```

若提示命令不存在，检查安装是否成功，并在安装后重新打开终端。macOS、Linux 等常见 shell 可以用 `command -v codex` 查位置；PowerShell 可以用 `Get-Command codex`。

不要复制其他电脑的绝对路径添加到环境变量。应核对你自己机器的安装位置，以及终端实际使用的环境。

## 命令能运行，但任务失败

| 现象 | 下一步 |
| --- | --- |
| 登录或授权失败 | 检查认证方式，参考安装与登录问题 |
| 找不到项目文件 | 检查当前目录，而不是反复安装 CLI |
| 测试或构建命令失败 | 查看项目运行时、依赖和命令输出 |
| 长时间无响应 | 检查是否等待输入、网络或子进程 |

能启动 Codex，只能证明 CLI 可运行，不能证明项目依赖也已装好。

## 怎样提供有效报错

记录系统、CLI 版本、命令、工作目录和关键输出。确认问题来自某次工具执行时，保留它的原始错误，而不只是“Codex 失败了”的总结。

若需要升级，按原安装渠道和 [CLI 官方说明](https://developers.openai.com/codex/cli/) 操作，避免同时安装多个副本后无法分清实际运行的是哪一个。

# Codex Cloud

## 适合谁

已经理解本地任务基本流程，准备处理远程仓库、长时间任务或并行任务的读者。

## Cloud 解决什么问题

Cloud 把任务放在远程环境中执行。它适合需要连接远程仓库、查看任务进度或把本地与远程工作分开的场景。

第一次使用 Codex 时不必从 Cloud 开始。先在本地完成一次可验证任务，再学习远程任务的权限、仓库连接和结果检查，会更安全。

## 开始前检查

- 确认连接的是你有权限访问的仓库。
- 确认任务不包含密钥、私人数据或不应上传的文件。
- 先明确任务要修改的范围和验证方式。
- 确认结果应该如何回到你的代码审查或 Git 工作流中。

## 使用 Cloud 的正确习惯

把 Cloud 当作执行环境，而不是跳过审查的理由。任务结束后仍要看修改内容、运行验证，并决定是否把结果合并回项目。

## 常见问题

**本地任务和 Cloud 任务怎么选？** 需要本地文件和即时交互时用本地；需要远程仓库、异步执行或并行跟进时考虑 Cloud。

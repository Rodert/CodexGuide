# 安装桌面 App

## 适合谁

已经准备好练习文件夹，现在需要进入 Codex 桌面 App 的读者。

## 开始前

确认你有可登录 Codex 的账号。下载入口、可用计划和系统要求可能会变化，请先查看 OpenAI 官方页面。

## 操作步骤

1. 从 [Codex 官方 App 说明](https://developers.openai.com/codex/app/) 查找下载入口，确认当前安装包支持你的系统和处理器，再按照系统提示安装。
2. 等下载完成后打开安装包，按系统提示完成安装，再启动 Codex。下载完文件不等于已经安装好应用。
3. 按 App 的登录提示操作；如果跳到浏览器，在官方授权页面完成后返回 App。
4. 核对当前账户，找到新建项目或任务的入口。此时先不发修改指令，下一课再选择练习目录。

能打开主界面、找到创建任务或选择项目的入口，并且账户显示正确，就完成了本节。暂时不用为了体验而授予所有目录权限。

如果系统没有适合的安装包，可改用 [CLI](./14-cli.md) 或 [VS Code](./15-vscode.md) 跟练。系统安全提示要先读清原因，公司设备的限制则需要管理员确认。

## 常见问题

**登录后看不到某个功能怎么办？** 先确认 App 版本、账号权限和地区可用性，再以官方说明为准。

**浏览器显示登录成功，但 App 没变化怎么办？** 返回刚才打开的 App，等待它完成回调；仍无变化时记录 App 提示和失败步骤，按 [登录排查](./48-install-login.md) 检查。不要把验证码、回调链接或令牌贴给他人。

# Skills

Skill 可以理解为一份可复用的工作方法。你经常让 Codex 按同一流程检查网页、整理文档或处理某类文件时，可以把步骤整理成 Skill，而不是每次重新解释。

## 和普通提示词有什么不同

提示词解决当前任务；Skill 除了说明，还可以包含参考资料、模板和脚本。它适合一类重复任务，不适合保存所有项目约定。长期项目规范仍放在 `AGENTS.md`。

一个 Skill 的核心通常是 `SKILL.md`。例如“网页验收”方法可以写成：

```markdown
---
name: webpage-check
description: 检查静态网页的内容、链接和窄屏布局。
---

1. 先读任务要求，列出验收项。
2. 检查 HTML 和 CSS 的引用关系。
3. 如果能预览，检查宽屏和窄屏。
4. 报告问题位置、影响和复现步骤。
5. 没有实际验证的项目单独说明。
```

这是内容示例，不能把文件随便放进任意文件夹就认为完成安装。存放路径、安装和发现方式要按当前入口支持的方式操作。

## 第一次怎么用

先选择来源明确、用途单一的 Skill，阅读它会执行什么，再在练习项目中调用。观察结果是否遵循了这套流程，而不是只出现了 Skill 名称。

安装方法暂按 [Skills 官方说明](https://developers.openai.com/codex/skills/) 核对；本节不提供未经当前版本验证的安装命令。

**常见误区：** 安装 Skill 不等于安装其中依赖的软件。需要浏览器、文档工具或外部凭证的工作流，仍要分别满足这些条件。

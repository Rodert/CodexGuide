# 下一步怎么学

你已经完成了第一次任务，也知道怎样描述需求和确认权限。接下来不需要把所有功能一次学完，按自己最常见的工作方式选择下一篇即可。

## 我想继续写代码

- 常用终端：阅读 [Codex CLI](./14-cli.md)。
- 常用编辑器：阅读 [VS Code 中使用 Codex](./15-vscode.md)。
- 已有项目：阅读 [项目、对话与工作目录](./17-projects.md)。

## 我想把 Codex 用得更稳

- 给项目写固定规则：阅读 [AGENTS.md](./18-agents-md.md)。
- 了解配置项：阅读 [config.toml](./19-config-toml.md)。
- 学会检查结果：回顾 [检查任务结果](./08-review-result.md)。

## 我想连接更多能力

- 想复用专门流程：阅读 [Skills](./23-skills.md)。
- 想连接外部工具：阅读 [MCP](./25-mcp.md)。
- 想了解第三方模型：阅读 [DeepSeek 与第三方模型](./22-third-party-models.md)。

## 我遇到问题了

从 [安装与登录问题](./48-install-login.md) 开始，按现象进入对应的排查页面。不要在不确定的情况下反复重装或放开权限。

## 提醒

Codex 的界面、功能和账号可用范围会持续变化。遇到价格、套餐、模型、权限或安全边界等时间敏感问题，优先查看文章末尾的官方资料与最后核对日期。

# JavaScript 练习项目

用于 CodexGuide 的测试、重构、Review 与 CI 练习。请把整个目录作为独立项目打开，不要嵌入其他项目后直接运行命令。

## 准备与运行

安装 Node.js 22 或更高版本，并确认终端位于本目录：

```bash
node --version
npm run check
npm test
```

没有第三方依赖，无需执行 npm install。初始版本只有一个测试，正常应显示 1 个通过、0 个失败；这是起点，并非完整测试覆盖。

## 文件

- tasks.js：统计已完成和待完成任务。
- tasks.test.js：使用 Node.js 自带测试工具的初始用例。
- package.json：声明 test 和 check 命令；这个项目没有 build 命令。
- .github/workflows/check.yml：将本目录内容放在独立 GitHub 仓库根目录后，执行同样检查的示例工作流。

## 行为约定

tasks 是对象数组。done 严格等于 true 才算已完成，其他值（含缺少 done）算待完成；不在本练习中处理 null 元素等不满足输入约定的情况。空数组两种计数均为 0，统计不应修改输入。

## 练习方式

1. 先运行初始检查，确认环境可用。
2. 补充空数组、全部完成、缺少 done、不修改输入等测试。
3. 在测试保护下整理重复循环，保持上述行为不变。
4. 可在副本中制造计数错误，再用测试定位、修复。

CI 工作流只有在你把项目上传到自己的练习仓库，并且 Actions 可用时才会远程运行。本地通过不等于远程已通过。
